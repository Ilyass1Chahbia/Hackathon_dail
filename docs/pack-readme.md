Read the [demo checklist](scorecard.md) and use the [Wolf handoff template](wolf-handoff-template.md). Follow the timing and presentation instructions given by your facilitator.

The event's configured harness and tools are your working environment. The data files require no service credentials. Any additional simulated records you create must be labeled and kept separate from the supplied test records. Do not alter the supplied records to make your prototype appear correct.
